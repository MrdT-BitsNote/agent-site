01 · 它做什么

一句需求进，一本小册子出

定位不是「告诉你有什么」，而是在有限预算、天数和体力下替你砍掉一半、排对顺序、并保证不翻车。

🗣 你给它一句需求

「10 月去大理玩 4 天，一家三口带娃，从岳阳出发，预算 6000。」
  • 出发地 / 目的地 / 天数
  • 人员构成 / 关系
  • 预算 / 出行方式
→

📖 它给你一本小册子

  • 逐日动线：每天几点出门、去几个点、怎么串
  • 住宿分房：几间房、什么床型、为什么这么分
  • 门票预约：多少钱、要不要抢、在哪买
  • 天气预检：那天能不能玩、不达标怎么改
  • 预算明细 + 装备清单 + 机位建议
🚄

全交通族系

公共交通（飞机 / 高铁 / 火车 / 客车 / 轮船）六方式比选出方案 A/B/C，叠加自驾、骑行、徒步、极限运动、演唱会锚点，按距离圈给「快 / 省 / 灵活」三视角。

六方式比选24 种节奏画像
🏍

骑摩托先查 5 件事

准驾车型证件 / 头盔 / 逐省高速准入 / 逐城禁摩 / 续航加油半径，每条带证据等级；加油决策点给动作序列，18 条线路带绿荫等级。

禁高速省 → 改走国道非要闯禁才拦你
🚐

房车 / 出境自检

按你声明的车型给限高、驾照牌照（C1 / B-A / C6）、补给半径与黑水灰水合规；出境护照 / 签证 / 疫苗 / 保险四证先查，不合格先拦。不推荐车型，不代办签证。

违法 / 不达标才拦没查证的标出来
🔍

可信度内核

信息分三档：稳定的 / 会变的 / 查不到的。会变的（天气、票价）强制联网现查并标日期；查不到的就明说待查，绝不编造。改需求只改提到的部分，不用整个重来。

03 · 行前体检

行前体检：出发前帮你查「这趟能不能走」

骑摩托、开房车、出境，规矩和开轿车完全不是一回事——它把这些「能不能走、合不合法、有没有坑」在出发前一项项查清楚，用最简单的方式告诉你。

约束汽车摩托 / 房车 / 出境的处理
证件有驾照就行准驾车型必须匹配（C1 骑摩托按无证驾驶）；房车 ≥6m 或 ≥4500kg 属黄牌需 B/A 照，拖挂需 C6
高速 / 限高随便上高速逐省不同：31 省里 17 省明文禁止摩托上高速——这种省只会提醒你改走国道（多花 40–80% 时间），你非要闯禁才真拦；房车按实测高度判限高
城区限行可绕逐城不同：45 城禁摩限摩，闯进去可能直接扣车
续航 / 补给600–800km，站密布200–400km，山区站间距 150km；加油决策点给动作序列；房车按水 85L/人·天等算补给半径
出境准入—护照 / 签证 / 疫苗 / 保险四证先查，不合格先拦再谈行程；没收录的国家一律说「查不到」
🚫 走不了：违法 / 条件不达标，出拦停页 ⚠️ 能走，但要先处理：给待办清单 ❓ 查不到：明说未核实，不装懂
三条判定纪律（1028 项回归断言锁死）：「禁止上高速」≠「不能去」，永远可以走国道；未查证的城市既不报红也不报绿，只标待核实；线路库只写稳定事实（走向、地形、季节），加油站坐标与实时路况必须出行前现查。

06 · 常见问题

常见问题

Q提示「这趟走不了」怎么办？
「走不了」意味着有违法或硬性条件没解决——此时小册子输出的是拦停页而非行程正文，只列出必须先解决的事与核验渠道。逐项解决后改参重跑即可。「要先处理」是待办清单，「查不到」是未核实（你自己再确认，系统不猜）。三种提示的含义见「03 行前体检」。
Q票价、门票、天气信息准吗？
两条硬规则：查不到的绝不编造，只给查询路径与购票时机；已可用的才标注——天气走 Open-Meteo 并打核验日期，车站码已缓存。完整口径见「04 数据底座」。
Q能帮我订票订酒店吗？能打印 PDF 吗？
订票订酒店不能，也不假装能——代订需要交易权限与实时库存。PDF 能：单文件 HTML，Ctrl+P 直接另存，导航自动隐藏、页边距自动压缩。改需求也不用重说：只改你提到的维度（天数 / 出发地 / 排量 / 照类 / 高速偏好）重跑即可。
Q摩托车能不能上高速？它怎么判断？
内置 31 省高速准入名单（13 允许 / 17 禁止 / 1 有条件）与 45 城禁摩限摩名单，逐省逐城带证据等级（法规明文 / 执法口径 / 第三方汇总）。禁高速省不拦你——只提醒改走国道（耗时 +40–80%）；只有你明确要走高速才判红灯。未查证的城市一律灰灯 + 需自行核实，绝不默认绿灯。
QSkill 和 Agent 应用，我该选哪个？
能力本体同一个包，差别在入口与归属：Skill 装进已有 Agent，一分钟装好但入口在别人 App 里；Agent 应用跑在你自己的服务器上，自有域名、数据不出境、能力零裁剪。详见「05 装进你的 Agent（两种形态）」。
