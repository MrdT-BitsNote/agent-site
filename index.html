01 · WHAT IT DOES

一句需求进，一本小册子出

不是「告诉你有什么」，而是在约束下替你决定：去哪、几天、怎么走、住哪、花多少。

🚄

六方式交通比选

先算圈层（≤30km / 30–150km / >150km），高铁、飞机、自驾、大巴同表比，给到达站落地动线；不硬塞不存在的航线、轮船。

🏨

关系 × 性别分房

按「关系 × 性别」判房间数与床型，不是人数除以二；情侣、带长辈、团建各有不同房型与预算口径。

🛂

出境四灯 + 摩旅门禁

护照、签证、疫苗、保险四灯拦未核验结论；摩旅再查证件、头盔、31 省高速准入、45 城禁摩。

🔍

三档事实，不编造

stable 直接用、volatile 强制联网打日期戳、unknown 灰灯只给查询指引；缺三元组即降灰灯。

03 · ONE PACK, ALL AGENTS

多功能技能包：复制一段，Agent 自己装

技能 0.2.301 + 专家 1.1.1 打成一个全平台合一包。把 START-HERE 复制给任意 Agent，它自报平台、自取子包、自校验 sha、按形态安装。

复制即装 · 推荐

一条指令，9 类平台通吃

包内 install.json 把「平台 → 子包 → 装法 → sha256」一一对应，Agent 读它就自己决定用哪个、怎么装。

  • 离线优先：子包就在包内 packages/
  • 自校验：sha256 前 16 位比对，不符即停
  • 自适配：skill / expert / bot+kb 自动识别
把 START-HERE.md 全文复制给目标 Agent → 它自报平台、自取包、自校验、按形态安装，装完回报版本。
包里有什么

一个 zip 装下全部

下载 WorldsTip-全平台合一包-0.2.301.zip，解压把 START-HERE.md 粘给 Agent 即可。

  • START-HERE.md 自安装总指令
  • install.json 机器可读清单
  • prompts/ 9 平台各一条可复制指令
